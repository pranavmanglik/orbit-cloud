# orbit-cloud architecture decisions

Architecture Decision Records (ADRs) document decisions that change this package's public contract, dependency direction, lifecycle owner, supported runtime, security boundary, or compatibility policy. Each record should include status, context, decision, alternatives, consequences, and evidence.
